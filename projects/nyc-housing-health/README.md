# NYC Housing Health Score Engine

**Academic data engineering and analytics project**

## Goal
Explore whether NYC housing complaint patterns can be organized into a practical property-level risk-scoring framework.

## Resume-reported scope
- More than **40 million** complaint records
- More than **20** complaint categories
- PostgreSQL, MongoDB and Spark
- Severity metrics and percentile benchmarks for higher-risk properties
