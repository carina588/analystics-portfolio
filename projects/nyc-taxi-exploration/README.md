# NYC Taxi Trip & Fare Exploratory Analysis

**Python data exploration assignment**

## Question
What do trip characteristics, payment methods and fare data reveal about NYC taxi operations?

## Source material
The uploaded archive includes `New_York_City_Taxi_Project.ipynb`, an accompanying PDF, and separate trip and fare CSVs. The notebook introduces the source as NYC Taxi and Limousine Commission data and describes the working sample as approximately **0.5%** of the larger dataset (roughly **850,000 trips**).

## Workflow
1. Load `nyc_data.csv` and `nyc_fare.csv`, parsing pickup and dropoff timestamps.
2. Inspect schema, row counts, types, descriptive statistics and missingness.
3. Examine vendor, rate code and payment type frequencies.
4. Analyze trip and fare distributions and visualize patterns.

## Reproducibility
The original notebook uses local CSV paths. The two large input CSVs are not published in this repository. A cleaned notebook will follow after reviewing output cells and removing local dependencies.

**Interpretation:** This is exploratory analysis, not a predictive model or causal study.
