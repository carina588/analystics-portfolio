# Project publishing standards

This repository is a curated professional portfolio rather than a dump of course submissions.

## Each published project should include
- A decision-focused business or research question
- Dataset provenance, coverage, grain and limitations
- A reproducible workflow and dependency information where possible
- Clearly labeled charts or dashboard screenshots from real outputs
- Findings supported by actual model output or analysis
- Implications, limitations and next steps
- Accurate attribution for collaborative work

## Privacy and intellectual property
Do not upload employer transaction data, proprietary notebooks, private credentials, personally identifying customer information, or third-party datasets without redistribution rights. Use public or synthetic substitutes and disclose them.

## Notebook quality checklist
- Remove hard-coded machine-specific paths
- Strip credentials, tokens and private data
- Make inputs configurable
- Explain execution order and dependencies
- Re-run the notebook and verify figures before claiming reproducibility
- Keep file sizes manageable and exclude large raw datasets

## Attribution
Collaborative projects should identify the project as team work. Personal contributions should be described specifically and should not imply sole authorship.
